# Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap».

## Описание проекта
Учебный интернет-магазин клавиатур KeyStore, разработанный на фреймворке Bootstrap 5. Проект продолжает визуальную стилистику Контрольной работы №1.

## Способ подключения Bootstrap
Bootstrap подключен **локально** (без CDN). Файлы фреймворка находятся в папке `vendor/bootstrap/`.

## Обязательные страницы
- `index.html` - главная страница;
- `catalog.html` - каталог товаров;
- `product.html` - страница товара;
- `order.html` - форма заявки;
- `contacts.html` - страница контактов (дополнительная страница).

## Использованные компоненты Bootstrap:
- **Сетка**: `container`, `row`, `col-*` (адаптивные колонки `col-md`, `col-lg`).
- **Навигация**: адаптивный `navbar` с выпадающим списком.
- **Карточки**: `card`, `card-body`, `card-img-top`.
- **Слайдер**: `carousel` на главной странице.
- **Вкладки**: `nav-tabs` на странице товара.
- **Модальное окно**: `modal` для быстрой заявки.
- **Уведомления**: `toast` при отправке форм.
- **Формы**: `form-control`, `form-select`, `input-group`, `form-check`.
- **Дополнительно**: `badge`, `alert`, `accordion`, `breadcrumb`.

## Самостоятельные доработки (повышенный уровень):
1. **Локальное подключение Bootstrap** (без CDN).
2. **Собственная цветовая тема**: через переменные в `custom.css` сайт перекрашен в фиолетовый стиль.
3. **Добавлена пятая страница** `contacts.html` с контактной информацией.
4. **Добавлены дополнительные компоненты**: карусель на главной, вкладки на странице товара, всплывающие уведомления (toast) при отправке форм.
5. **Горизонтальный свайп (Scroll Snap)**: реализована галерея фотографий на странице товара.
6. **Улучшена визуальная часть**: добавлены плавные анимации наведения (hover) на карточки товаров и тени.
7. **Настроены SEO-теги** (Open Graph) и `sitemap.xml`.
